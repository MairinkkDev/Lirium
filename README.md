# Lirium
Repositório oficial dos projetos e aplicações web desenvolvidos pela Lirium, uma empresa fictícia focada na criação de soluções modernas para desenvolvedores.

🚀 Sobre a Lirium

A Lirium desenvolve aplicações web pensadas para facilitar o trabalho de desenvolvedores, oferecendo ferramentas simples, eficientes e acessíveis para diferentes necessidades do desenvolvimento de software.

Tecnologias: HTML • CSS • JavaScript • React • Node.js • APIs • Git
